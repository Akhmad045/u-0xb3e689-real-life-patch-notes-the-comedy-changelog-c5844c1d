## What it does

`main.py` writes one line to `/output/entry.txt`: a software patch note for a bug in real life — the doorway effect, where crossing a doorway wipes your working memory of why you entered the room — written in the terse register of a real release note.

## Run it

```sh
python3 main.py
```

Stdlib only, no network. The output is a single line of 106 characters, within the 160-character cap.
